### Featured projects

These portfolio implementations use synthetic data and include runnable source, tests, and setup instructions. They are independently built demonstrations, not copies of employer systems.

#### [RingLab — Lock-Free Circular Buffer](https://github.com/nceeg01/blahblaah/tree/main/ringlab)

A C++20 single-producer/single-consumer queue with atomic acquire/release handoffs, aligned counters, and a reproducible mutex comparison. The interactive browser lab shows FIFO order, wraparound, and backpressure.

`C++20` `Atomics` `Concurrency` `Benchmarking`

**Verification:** one million concurrent transfers with FIFO validation, boundary tests, and browser-model tests. Recorded benchmark results describe their execution environment; no universal speedup is claimed.

#### [TickStream — Real-Time Market Data Aggregator](https://github.com/nceeg01/blahblaah/tree/main/tickstream)

A Python asyncio pipeline that consumes three synthetic WebSocket feeds, normalizes tick schemas, tracks duplicates and late events, and persists accepted records to SQLite. The browser workspace includes a live synthetic tape, quality monitoring, replay, and exports.

`Python` `asyncio` `WebSockets` `SQLite` `JavaScript`

**Verification:** integration tests exercise actual local WebSocket feeds, normalized output, and the snapshot API. All market data is synthetic.

#### [MediaFlow — Media ETL Workspace](https://github.com/nceeg01/blahblaah/tree/main/mediaflow)

A media data pipeline with CSV/JSON ingestion, editable schema mapping, normalization, validation, duplicate handling, and clean-data exports. Includes a Python batch workflow with transactional SQLite storage.

`Python` `ETL` `SQL` `Data quality` `JavaScript`

**Verification:** eight automated tests covering parsing, validation, deduplication, exports, and database behavior.
